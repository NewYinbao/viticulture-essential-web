## 服务端提示投影

新增只读的可用性计算，并把原因随当前玩家视图返回：

- `actionReasons`：行动当前已知不满足的前置条件。
- `cardReasons`：本人手牌当前不可用的原因。
- `optionReasons`：待决选择中具体选项不可用的原因。

提示计算覆盖金币、建筑、田地、工人、配方及部分访客分支。它不执行行动、不抽牌、不预测牌序，也不代替最终服务端规则校验。空原因只表示没有发现已知前置条件缺失，不保证任意参数组合都合法。

## 前端反馈

- 可选行动显示绿色边框和“可派遣”；条件不足的行动显示虚线和简短原因。
- 悬停行动时，对应类型手牌同步描边。
- 鼠标悬停、键盘聚焦和手机点按均可查看原因。
- 不可用控件保留可聚焦性，但不会发送非法行动。
- 访客分支显示可用状态，默认选择可用分支；常见费用和收益进入短标签。
- 手牌资源未选齐时禁用确认并显示单句缺项；选齐后显示“已就绪”。
- 建筑选项显示当次费用及缺少的金币或酒窖前置条件。
