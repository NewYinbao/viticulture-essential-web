## 卡片式操作

- 工人、格位、奖励、建筑、手牌、田地、葡萄和酒均使用可见按钮卡片，不再依赖下拉框。
- 八座基础建筑全部展示，包含已拥有设施；显示原价、当次费用、折扣、拥有状态和前置条件。
- 访客、订单和葡萄藤沿用手牌插画和中文牌名；详细牌面放在面板内悬浮说明。
- 种植通过藤卡再选田地卡，并校验多藤合计容量；订单通过酒卡选择交付资源。
- 酿酒先选酒瓶，再分配葡萄，显示种类、预计品质、酒窖降级和瓶数上限。

## 桌面与窄屏行为

确认区固定在面板底部。手机布局提供面板内滚动和“查看庄园／当前行动”往返；庄园与手牌仍可查看和交互。Esc、取消和返回不提交请求；SSE 新 revision 或 409 会清理旧选择。
