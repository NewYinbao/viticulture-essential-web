# 操作体验检查与改动

2026-09-11；实际使用 Chromium 检查桌面与 390×844 手机视口，保留原有酒庄配色及 SVG 插画。

| 观察到的问题 | 已做的修改 |
| --- | --- |

确认按钮固定在棋盘内操作面板底部，窄屏也保持可达。真实浏览器验证了拔藤提交及桃红酒预览与服务器结果一致；没有仅以 DOM 模拟替代服务端操作。

## 试玩反馈后的提示优化

- 当前可选行动使用绿色边框和“可派遣”角标；不可用行动用虚线与“条件不足”。悬停行动时，对应类型手牌同步描边。
- 鼠标悬停、键盘聚焦或手机点按可显示简短原因。不可用按钮保留聚焦能力，但不会发送无效行动。
- 服务端只读计算金币、建筑、田地、工人、配方和部分访客分支的前置条件，不运行行动、不抽牌、不预测随机结果。前端补充当前字段所需资源的数量检查。
- 访客选项显示“可选／不可用”，默认选择可用分支；常见费用和收益直接写在短按钮标签内，长牌面与费用解释折叠。
- 手牌资源未选齐时禁用确认，旁边只显示一句所缺条件；选齐后显示“已就绪”。建造选项标记当前费用及缺少的金币／前置酒窖。

这些是必要条件和资源选择提示，最终仍由服务端校验具体组合；未把允许零收益的效果一律视为违法。新增测试覆盖原因气泡、键盘聚焦、费用不足的选项、资源数量与确认按钮的联动，同时验证提示不修改存档状态或泄露他人的手牌信息。

本地截图和测试报告位于 `artifacts/usability/`；属于测试产物，不提交到仓库。完整游戏测试和夹具测试分别记录，详见 [testing.md](../../../guides/testing.md)。

## 公共棋盘内的卡片操作面板

- 统一原来两套公共行动弹窗为 `action-panel.js`，在 `#board` 内展开，替换行动列表；起床奖励在 `#wake-panel` 内展开。移除全屏 dialog、背景遮罩和模糊样式。庄园与手牌可以直接查看、交互，不丢失当前选择。
- 工人、行动格、奖励、建筑、手牌、田地、葡萄和酒全部使用按钮卡片，无下拉菜单或隐藏 select。卡片以描边、勾选、虚线区分已选和条件不足；确认前仅保留一条简短状态。
- 建造展示全部八座建筑，包括已有设施。卡片显示本次费用和折扣；悬停或键盘聚焦显示作用、原价、当前费用、拥有状态和前置条件。改变行动格或放弃奖励，会重新计算费用和确认状态。
- 访客、订单与葡萄藤沿用手牌插画和中文牌名，详细牌面放在悬浮说明中。订单再点酒卡；种植再点田地卡，并检查多张藤合计容量。
- 酿酒先选酒瓶，再点葡萄分配；预览保留当前酒瓶编号，显示酒种、品质和酒窖降级。悬浮说明限制在面板边界内。
- 面板顶部保留自己的金币、胜利分、待命工人；手机使用内部滚动、固定确认区和“查看庄园／当前行动”往返导航。Esc、取消和返回均不提交；SSE 新 revision 或 409 会清理旧选择。

验证：扩展 `usability-test.cjs`，使用隔离存档和真实服务器验证八座建筑状态／折扣、建筑扣费、访客牌 ID、订单交付、收获、双藤同田种植、拔藤、桃红酒与起床奖励；检查桌面／390px 面板范围、气泡边界、庄园可交互、取消无请求和过期局面清理。截图见 `artifacts/usability/desktop-building-panel.png`、`mobile-building-panel.png`、`mobile-visitor-cards.png`。
