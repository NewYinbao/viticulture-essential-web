## 独立复审

[功能审查 A](FINAL_FUNCTIONAL_REVIEW_A-20260912.md) 与 [功能审查 B](FINAL_FUNCTIONAL_REVIEW_B-20260912.md) 分别在独立任务和临时副本中核实问题、复核修复。两项问题均已关闭：

1. 公共 Action 可伪造额外格位奖励。现在入口忽略客户端 `BonusOverride`，只有服务端已验证的续步恢复内部奖励；真实 HTTP、落盘和重放测试通过。
2. Farmer 的预约培训在只有 3 金币时被错误删除，UI 同时按 4 金币禁用。现在预检与执行共享已保存的工人/奖励，只向行动者显示折扣；真实 Edge 跨季、重启及扣费流程通过。

两个任务对上述功能快照均未发现新的可复现问题。密码专项另有独立复审通过记录。复审不构成所有输入和卡牌组合绝对无错误的保证。

## 覆盖边界

覆盖表包含 167 个扩展条目、368 条实际 Go 测试引用和 132 个唯一测试函数，引用均存在。24 自然局策略不打访客；逐建筑为明确标注的夹具。浏览器尚未直接执行 7 类特殊工人、37 张 Moor 和 74 张 Rhine 的具体效果；它们有领域测试，但不能把目录或渲染通过写成浏览器效果执行。Rhine 179 项表示初始分支注册/渲染，未穷举所有嵌套、人数、牌序与模块组合。

本机 WSL 没有 C 编译器，本地未运行 race；仓库 CI 配置另行执行。测试仅使用自建临时数据和随机回环端口；现用服务、真实对局和旧 EXE 均未被替换。
