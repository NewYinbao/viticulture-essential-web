# 操作体验检查与改动

2026-09-11；实际使用 Chromium 检查桌面与 390×844 手机视口，保留原有酒庄配色及 SVG 插画。

| 观察到的问题 | 已做的修改 |
| --- | --- |
| 版本提示反复出现，行动区域被挤到下方 | 移除重复横幅；牌堆／家族默认折叠；范围说明集中在规则说明 |
| 手机上的手牌在整块庄园之后，需要长距离滚动 | 增加固定底部导航，桌面使用顶部吸附导航 |
| 各类手牌混排，找牌费时 | 按类型筛选并显示数量；待决选择自动恢复全部，避免隐藏可选牌 |
| 返回入口后恢复座位只能靠刷新 | 提供“回到上次的房间”按钮 |
| 第 2 格先被使用时，工人却画到第 1 格 | 按 seat.slot 匹配绘制；奖励格有标签；无限金币行动与私人轭分别显示 |
| 工人、轭或基本资源不足时仍可打开无效行动 | 在按钮中直接显示原因并禁用；服务器继续做完整规则验证 |
| 默认工人进不了已满的普通格 | 在可用时默认选择大工人；奖励默认值不再要求额外点选 |
| 拔藤选择与田地独立，易选错牌 | 轭的拔藤列表跟随田地，只列该田地上的藤 |
| 种植表单英文牌名、没有容量提示 | 中文牌名、已种数值／容量、缺失建筑提示；只启用被勾选藤的田地选择 |
| 酿酒只分组，不知道结果／可酿几瓶 | 显示实时瓶数上限、酒种、预计品质及降级原因；提交前检查瓶数 |
| SSE 更新后旧弹窗还可提交 | 新 revision 到来关闭旧弹窗并提示；409 时拉取最新局面 |

表单提交按钮在窄屏弹窗内保持可达。真实浏览器验证了拔藤提交及桃红酒预览与服务器结果一致；没有仅以 DOM 模拟替代服务端操作。

本地截图和测试报告位于 `artifacts/usability/`；属于测试产物，不提交到仓库。完整游戏测试和夹具测试分别记录，详见 [testing.md](../../../guides/testing.md)。
