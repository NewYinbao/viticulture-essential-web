# Buy me a HEYTEA：赞助码维护

中英文 README 共用[微信二维码](../assets/buy-me-a-heytea-wechat.png)。维护者于 2026-09-12 提供新版图片，并确认已经配置几个预设金额。扫码后在微信页面选择金额；README 不重复写死档位。

图片仅裁剪二维码及白色边缘，保留中央头像；不重绘、不修改二维码内容。PNG 的 610 × 610 像素与原图对应区域逐像素一致。未进行实际付款测试，金额和收款信息以微信页面为准。后续更新时替换同名 PNG，并检查两份 README 的显示。

## 预设金额的实现方式

对于静态 README，使用微信端已配置好的收款或赞赏码即可，无需支付后端。腾讯 CNB 的[官方赞助说明](https://docs.cnb.cool/zh/sponsor.html)也采用上传微信赞赏码的方式。具体设置入口和可选金额以微信客户端为准；本项目不从截图推断二维码类别或具体档位。

若未来需要程序为每笔订单指定金额，微信支付[Native 下单接口](https://pay.wechatpay.cn/doc/v3/merchant/4012791877)支持 amount.total（单位：分），但需要商户配置、签名和服务端下单；返回的 code_url 有效期为 2 小时，不适合直接作为永久 README 图片。当前项目没有接入该支付流程。
