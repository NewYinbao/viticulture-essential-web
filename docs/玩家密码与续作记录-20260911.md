## 玩家密码

密码绑定“房间 + 玩家座位”，不是全站同名账号。新建或加入新座位需设置 8–128 字密码；同房间同名恢复必须验证密码。已开始、已满或已结束的房间也能验证后恢复原座位。

密码独立存储为随机盐与 PBKDF2-SHA256 哈希；不进入游戏 View、浏览器本地存储或日志。新登录、改密撤销该座位全部旧会话；退出撤销当前会话。旧 SSE/轮询窗口会清空手牌并返回入口。保存失败时凭据与会话一并回滚。

旧存档无法从已有 token 判断谁是原玩家。因此旧座位首次设密需要“原会话 + 服务器本机启动窗口中的一次性验证码”；设密前禁止读取手牌与执行行动。验证码只保存在内存，成功后失效，重启更换。服务器房主应把对应座位验证码交给原玩家。新座位没有此额外步骤。

主要入口：`internal/server/password.go`、`http.go`、`events.go`、`server.go`，前端 `password-ui.js` 与 `app.js`。测试包括错误密码、旧存档、重启、存储失败、旧 token/SSE/轮询撤销、限流和跨浏览器隐私。独立任务《葡萄酒庄园玩家密码独立审查》二轮复审结论为 password 范围 clean；扩展整体已完成两份独立功能复审，另有代码风格与工程审查。
